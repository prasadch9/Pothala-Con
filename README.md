# Pothala Consultants & Services — Next.js website

## Run
npm install
npm run dev      # http://localhost:3000
npm run build && npm start

## Replace your data
- Business phone / email / address / hours + ALL service content: components/ServicesData.jsx
- Hero images (7): public/hero/hero-1.jpg ... hero-7.jpg  (hero text: components/Hero.jsx -> SLIDES)
- Logo: public/logo.png
- Page text is written directly inside each page .jsx (app/page.jsx, app/about/page.jsx, app/contact/page.jsx)
